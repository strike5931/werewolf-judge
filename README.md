# 狼人殺裁判台

給裁判用的單頁工具：記錄身份、夜晚流程、出局與勝負。可以加到 iPhone 主畫面當 app 用。

- 公開網站：https://strike5931.github.io/werewolf-judge/
- 整個工具是一個 HTML 檔，沒有後端、沒有帳號。對局狀態存在各自手機的瀏覽器裡。

## 三種玩法

| 玩法 | 牌在哪 | 夜晚怎麼進行 | 需要開房間 |
|---|---|---|---|
| 現場有牌 | 實體牌 | 閉眼、比手勢，裁判在裁判台記錄 | 不用（要開也可以，手機只顯示階段） |
| 現場沒牌 | 各自手機上 | 閉眼、比手勢，裁判在裁判台記錄 | 要 |
| 線上玩 | 各自手機上 | 輪到的人在自己手機上選，結果直接出現在裁判台 | 要 |

三種玩法用的是同一套規則判定，差別只在「牌怎麼發」和「選擇由誰輸入」。

### 現場有牌

1. 首頁設定人數、卡牌、規則 → 「下一步：座位與發牌」。
2. 直接按「開始第一夜」。
3. 第一夜每個角色睜眼時，裁判點座位記錄他是誰（工具會擋住下一步，直到記完）。
4. 之後照畫面上的台詞念，點選各角色的選擇，最後「天亮，結算」。

### 現場沒牌

1. 首頁設定 → 「下一步：座位與發牌」→「連線發牌：開房間」→ 玩法選「現場沒牌」。
2. 玩家用 QR code、房號或分享連結加入，填名字、選自己的座位。
3. 裁判按「隨機發牌」，再按「開始第一夜」。牌自動送到每個人手機。
4. 玩家手機：牌背朝上，點一下翻面看身份，正面 10 秒後自動蓋回，換階段或切走畫面時也會馬上蓋回；階段切換時跳提示（天黑請閉眼／天亮了／你已出局／遊戲結束）。**不會顯示任何選項**。
5. 夜晚照現場的方式進行：閉眼、比手勢，裁判在裁判台點選。

### 備用：傳手機看牌

房間連不上、或有人沒手機時用。「隨機發牌」後，點發牌頁下方的「傳手機看牌」，用裁判這支手機讓每個人輪流看自己的身份。不需要網路。

### 線上玩

1. 前三步同「現場沒牌」，玩法選「線上玩」。
2. 裁判照常按「下一步」推進。輪到誰，誰的手機就跳出行動面板；沒輪到的人只看到「夜晚進行中」。
3. 玩家選完，結果直接顯示在裁判台同一個位置。沒連線的座位由裁判代選。
4. 出局可開槍的人（獵人、狼王、交易來的獵槍）在手機上選要帶走誰或不開槍。
5. 仍由裁判記錄的：白天投票、警長競選與警徽移交、白狼王自爆、騎士決鬥。

各角色在手機上看到的：

| 角色 | 內容 |
|---|---|
| 狼人 | 狼隊友是誰、選刀口（全隊共用，最後選的算數） |
| 狼弟（覺醒後） | 多一組額外刀口 |
| 狼兄、狼弟 | 第一夜互認時顯示兄弟是幾號 |
| 女巫 | 今晚誰被襲擊（解藥還在才會知道）、救不救、毒誰 |
| 預言家 | 選人後顯示好人或狼人；要點兩次確認，確認後不能改 |
| 守衛、狼美人 | 選對象 |
| 黑市商人 | 選技能和對象 |
| 幸運兒 | 拿到技能時通知；隔晚起在幸運兒階段使用 |
| 獵人 | 夜晚顯示能不能開槍 |

## 夜晚順序

入夜 →（第一夜：狼兄弟互認）→ 守衛 → 狼人 → 狼美人 → 黑市商人 → 女巫 → 預言家 →（交易後：幸運兒）→ 獵人 →（交易前：幸運兒）→（第一夜：確認白痴／騎士）→ 天亮

沒有的角色自動跳過。已出局的角色照樣念台詞並停頓，不讓場上聽出來。

- **獵人永遠最後**：所有毒都下完了，才告訴他能不能開槍。
- **幸運兒**這一步有兩種位置，同一夜只會出現一個：
  - **還沒交易過**（含第一夜）：排在獵人**後面**，提醒裁判今晚有沒有新的幸運兒要單獨叫起來通知。有的話畫面顯示幾號、要比什麼手勢；沒有就直接下一步。
  - **交易過之後**：排在獵人**前面**，讓幸運兒使用交易來的技能。

## 我們這桌的規則

預設值，首頁「規則」可以改：

- 女巫僅首夜可自救；同一晚只能用一瓶藥；同守同救該玩家死亡。
- 屠邊；有警長；僅首夜死者有遺言。
- 被毒的人不能發動技能（獵人、狼王不能開槍）。殉情者也不能。

黑市商人＋狼兄狼弟板子：

- **狼弟**：狼兄在場時不進狼坑，被查驗是好人。狼兄出局**當晚**起加入狼隊，並多一刀，整局一次、可保留。額外一刀和狼刀砍同一人時，解藥和守衛都救不了。
- **黑市商人**：整局交易一次，狼人行動後睜眼。手勢 1 毒藥、2 獵槍、3 查驗。交易到狼人（含未覺醒的狼弟）則**商人出局**，對方不暴露。
- **幸運兒**：交易成立當晚，在「天亮了……等一下」時單獨通知。隔晚起才能用。
  - 交易來的技能一律在幸運兒階段單獨睜眼使用。預言家拿到查驗、女巫拿到毒藥也一樣：先在自己那一步用完閉眼，幸運兒階段再用一次。
  - 拿到獵槍：幸運兒階段看開槍手勢，晚上不能開。白天被放逐或被刀出局時**當下**開槍；被毒不能開。
  - 獵人拿到獵槍＝兩把槍，出局時開兩槍。

## 連線房間

- 裁判手機是主機，整場要停在裁判台頁面、不能鎖屏。重新整理後房間會自動重開，玩家自動接回。
- 加入方式三種：相機掃 QR code、首頁「我是玩家 → 加入房間」輸入四位數房號、裁判按「分享連結」。
- 每支手機只會收到自己的那一張牌。
- 發牌前請核對名單。房號只有四位數，陌生人猜到可以進來占座位；名單上每個座位有 ✕ 可以請出去。發牌後就不能再選座位。
- 線上玩時，有人斷線（超過 12 秒沒回應）或按離開，遊戲會暫停。裁判可以選繼續（由裁判代選）、重開房間（房號不變）或關閉房間；斷線的人連回來自動繼續，離開的人可以用原房號坐回原位。現場有牌、現場沒牌時只提示離線，不暫停。
- **開著 VPN 的手機連不上**（實際遇過）：會卡在「（3/3）正在和裁判的手機建立連線」。關掉 VPN 就好。裁判的手機同樣不能開。
- 手機之間靠 PeerJS 的免費公用服務牽線，偶爾會連不上。牽線時該服務看得到房號和 IP。

## 其他功能

- **選單**：本局紀錄、裁判小抄、卡牌圖鑑（可點擊翻面、拖曳旋轉）、發言計時器、外觀（跟隨日夜／深色／淺色／跟隨手機）、連線房間、快速測試。
- **外觀預設跟隨日夜**：白天是白金配色，其餘時間是黑金配色。
- **牌的畫法**：平塗的塔羅牌，每張一個主色。好人牌淺底，狼人牌黑底（一般狼人暗紫、狼王／白狼王／狼美人深紅）。牌面底部橫幅留白，名字由網頁疊上去。
- **復原**：最多 60 步。
- **遮蔽**：把所有身份蓋成牌背，手機要給別人看時用。
- **快速測試**：直接跳到某個情境的關鍵步驟，測完按「結束測試」回到原本的局。

## 開發

| 檔案 | 用途 |
|---|---|
| `werewolf-judge.html` | 原始檔，所有修改都改這個 |
| `index.html` | 由 `tools/build.py` 產生，GitHub Pages 發佈的就是它。不要手改 |
| `tools/build.py` | 把 `art/` 的圖壓成小張嵌進頁面，並產生 `index.html` |
| `tools/gen_art.py` | 用 OpenAI 產角色卡和介面圖（金鑰從 `OPENAI_API_KEY` 環境變數讀） |
| `tools/gen_samples.py` | 新畫法定案前的試產紀錄，保留各輪提示詞 |
| `tools/e2e/` | 無頭瀏覽器測試 |
| `art/` | 原圖，只留在本機，不進版控 |

```bash
python3 tools/build.py
```

```bash
python3 -m http.server 8765
```

```bash
cd tools/e2e && npm install && node run.mjs
```

測試會開一個裁判和多個玩家的無頭瀏覽器，實際透過 PeerJS 連線，把三種玩法各跑一輪。需要網路。

推到 `main` 分支後 GitHub Pages 會自動部署。
